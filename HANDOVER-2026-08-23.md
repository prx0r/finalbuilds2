## Key decisions (do not relitigate without reading)

1. sandboxd retired from critical path — worktree pipeline replaced it.
2. Two canonical product shapes only: platform capability module (Python/FastAPI)
   and edge site (Astro/CF Pages). Rust CLI only when measured need exists.
3. Single provider: opencode-go ox-alpha-free everywhere; no fallbacks configured.
4. Builders never decide PASS; only verify-candidate.sh output authorizes promotion;
   promotion merges the receipt's EXACT commit SHA.
5. Hypotheses are versioned research programs (draft->probation->active->promoted/
   branch/demoted/retired); promote gates >=8 resolved forecasts, >=3 entities,
   >=2 windows. Thompson allocation rejected until repeatable arms exist.
6. Hydra = provenance/lineage brain; canonical quantitative state lives in files/
   SQLite; posterior draws belong in artifact storage, never graph nodes.
7. H1-H3 are SEED hypotheses; future ones crystallize from evidence clusters
   (convergence-detector) and pass adversarial admission.
